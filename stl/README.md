# Ready-to-print STL files

Generated by `python scripts/build.py` from `src/bay2rack.scad` - do not edit by hand.
Every file is already in print orientation (front face down, no supports).
Defaults: 6in rack with 10in mini rack rules (134.925 mm hole spacing, EIA-310), M5 heat-set inserts for the rack, M3 heat-set inserts for the bay screws. Need something else? Change it in the Customizer and export your own.
The devices, their cables and power supplies are not included; the build guide is in [docs/BUILD.md](../docs/BUILD.md).
